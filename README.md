I made this repo to encourage myself and help my friends learn vim motions.
## What's inside

- [`cheatsheet.md`](cheatsheet.md): a quick reference for the commands, for looking things up
- [`practice/Practice_vim.md`](practice/Practice_vim.md): exercises you do inside vim
- [`practice/gg.py`](practice/gg.py): a Python file used in the buffers and auto-complete exercise

## How to use it

```
git clone https://github.com/wahabxvii/vim_motions_are_fun
cd vim_motions_are_fun/practice
vim Practice_Vim.md
```

Open the practice file in vim instead of reading it on GitHub, so you can edit it and practice for real. Start it from inside `practice/` so `:e gg.py` works. Each exercise has the correct line on top and a messy line below, and you fix the bottom line using the commands in the angle brackets.

## What you'll practice

Modes, moving around, searching, editing, operators, indenting, marks, buffers, split panes, and options.
